# Wagmidle Game Rules

Welcome to **Wagmidle** — the daily crypto guessing game! Test your knowledge of the crypto ecosystem across three exciting game modes.

---

## 🎮 Game Modes

### 🎭 Character Game

Guess the **crypto personality** of the day!

**How to Play:**

1. Search for a crypto figure by name
2. Submit your guess
3. Receive feedback on each attribute:
   - **Role** — The figure's primary role (e.g., Founder, CEO, Developer)
   - **Primary Chain** — The blockchain they're most associated with
   - **Year Joined** — When they entered the crypto space

**Feedback System:**

- ✅ **Green** = Exact match
- 🔼 **Arrow Up** = The correct answer is higher (for years)
- 🔽 **Arrow Down** = The correct answer is lower (for years)
- ❌ **Red** = No match

---

### 🪙 Token Game

Identify the **mystery cryptocurrency token** of the day!

**How to Play:**

1. Search for a token by name or ticker
2. Submit your guess
3. Receive feedback on each attribute:
   - **Ticker** — The token's trading symbol
   - **Network** — Primary blockchain network (e.g., Ethereum, Solana, Native)
   - **Category** — Token type (e.g., Layer 1, DeFi, Meme, Stablecoin)
   - **Launch Year** — When the token was launched
   - **Market Cap Rank** — Current ranking by market capitalization

**Feedback System:**

- ✅ **Green** = Exact match
- 🔼 **Arrow Up** = The correct answer is higher
- 🔽 **Arrow Down** = The correct answer is lower
- ❌ **Red** = No match

---

### 🖼️ NFT Game

Guess the **NFT collection** from a progressively revealed image!

**How to Play:**

1. View the heavily zoomed/pixelated NFT image
2. Search for an NFT collection by name
3. Submit your guess
4. With each incorrect guess, the image becomes clearer (zoom out effect)
5. Keep guessing until you identify the collection!

**Visual Clues:**

- The image starts extremely zoomed in
- Each wrong guess reveals more of the artwork
- Pay attention to colors, patterns, and art style

---

## 📊 Game Mechanics

### Daily Reset

- All games reset at **midnight UTC**
- A new character, token, and NFT are selected each day
- Your progress is saved locally until the next reset

### Progress Tracking

- Your guesses are saved automatically
- Return anytime to continue where you left off
- Win states are preserved until daily reset

### No Guess Limit

- Take as many guesses as you need
- But fewer guesses = more impressive wins!

## 💡 Tips & Strategies

### Character Game Tips

- Pay attention to the role — it narrows down candidates significantly
- Primary chain association is a strong indicator
- Year joined helps distinguish veterans from newcomers

### Token Game Tips

- Start with well-known tokens to eliminate categories
- Network narrows down the possibilities quickly
- Market cap rank gives you directional hints (higher/lower)

### NFT Game Tips

- Focus on distinctive art styles and color palettes
- Popular collections have recognizable traits
- Chain and category clues can help if you're stuck
